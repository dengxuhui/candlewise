# 实战分析框架

经过六个模块的系统学习，是时候将所有知识整合为一套**可重复执行的实战分析框架**。这个框架由四个步骤构成，覆盖从宏观趋势到具体信号的完整判读链条。

---

## 四步分析框架

```
Step 1：判断趋势方向
Step 2：识别关键价位
Step 3：等待 K 线形态信号
Step 4：用成交量验证
```

---

## Step 1：判断趋势方向

在分析任何具体 K 线形态之前，先问自己：**"大趋势是涨还是跌？"**

```candle-demo:trend-up
```

判断工具：
- **MA20 方向**：向上 = 上升趋势，向下 = 下降趋势，走平 = 横盘
- **高点低点结构**：高点与低点均上移 = 上升；均下移 = 下降
- **MA5 与 MA20 位置关系**：MA5 在 MA20 上方 = 多头排列，反之 = 空头排列

> **原则**：顺势而为。在上升趋势中只找做多信号（底部反转形态），在下降趋势中只找做空信号（顶部反转形态）。

---

## Step 2：识别关键价位

趋势方向确认后，找到**当前价格所处的关键区域**：

```candle-demo:key-levels
```

关键价位的识别方法：
- **历史支撑位**：前期多次反弹的价格区域
- **历史阻力位**：前期多次回落的价格区域
- **均线支撑/阻力**：MA20 在趋势中的动态价位
- **角色转换位**：原支撑变阻力或原阻力变支撑

> **原则**：只在关键价位等待信号，不在"空中"追涨杀跌。

---

## Step 3：等待 K 线形态信号

在关键价位处，耐心等待**与趋势方向一致**的 K 线形态出现：

```candle-demo:pattern-at-level
```

- 上升趋势中回踩关键支撑 → 等待**看涨形态**（锤子线、启明星、阳线吞没等）
- 下降趋势中反弹至关键阻力 → 等待**看跌形态**（流星线、黄昏之星、阴线吞没等）

> **原则**：形态必须与趋势和位置共振，孤立出现的形态不入场。

---

## Step 4：用成交量验证

```candle-demo:volume-at-pattern
```

形态信号出现后，检查成交量：
- 反转形态当日或次日**放量** → 信号确认，资金方向明确
- 反转形态出现但**缩量** → 信号存疑，等待进一步确认

成交量是"量价配合"的最后一道门：形态告诉你**方向**，成交量告诉你**力度**。

## 框架的边界

这套框架是提高胜率的工具，不是盈利保证。以下几点必须清楚：

| 局限 | 说明 |
|---|---|
| 无法预测 | K 线分析是概率工具，不是预言 |
| 市场会变 | 历史规律未来可能失效，持续学习不可缺少 |
| 仍需止损 | 即使三重共振信号，也有失败概率，必须设置止损 |
| 不适用所有市场 | 极端事件（黑天鹅）会使所有技术分析失效 |

> **最后的原则**：框架给你概率优势，纪律和资金管理让你能在长期坚持下去。技术分析是工具，而不是答案。

## 小结

- 四步框架：趋势判断 → 关键位识别 → 形态等待 → 量能验证
- 顺势操作：上升趋势找做多信号，下降趋势找做空信号
- 在关键价位等待形态，不追涨杀跌
- 成交量是信号的最后验证器，量价配合才是高质量信号
- 技术分析提供概率优势，止损和纪律是长期生存的保障
