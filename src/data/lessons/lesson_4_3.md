# 实战分析框架：从宏到微

前两节课建立了理论基础。这节课给你一套**可直接上手的分析流程**——每次打开一张 K 线图，都从这 4 个步骤出发。

---

## 为什么要有分析框架？

没有框架的分析，容易陷入两个极端：

- **过度分析**：看到处处都是信号，却不知道该信哪个
- **欠分析**：只盯着最近几根 K 线，忽视大背景

框架的作用是**强制你按顺序思考**，从宏观到微观，层层过滤。

---

## 四步分析法

### 第一步：判断趋势方向（宏观背景）

拉开视野，看 MA20 的方向：

```candle-demo:trend-up
```

```candle-demo:trend-down
```

**问自己：**
- MA20 是向上、向下，还是走平？
- 价格整体是在 MA20 上方还是下方？
- 近期有没有趋势反转的迹象？

**决策树：**

```
MA20 向上，价格 > MA20
  → 趋势向上，优先寻找看涨信号（回调做多机会）

MA20 向下，价格 < MA20
  → 趋势向下，优先寻找看跌信号（反弹做空/减仓机会）

MA20 走平，价格在 MA20 附近徘徊
  → 震荡行情，形态信号可靠性低，谨慎操作
```

> **记忆口诀**：顺势而为，逆势不操作。

---

### 第二步：标注关键价位（支撑/阻力）

在图上找出近期明显的支撑位和阻力位：

```candle-demo:key-levels
```

**如何识别关键价位？**

- 价格多次在某价位附近止跌 → 支撑位
- 价格多次在某价位附近止涨 → 阻力位
- 已被突破的阻力位 → 转化为支撑位（角色转换）
- MA20 当前所在位置（动态支撑/阻力）

**为什么先标关键价位？**

因为 K 线形态只有在关键价位附近出现才有意义。你需要先知道"哪里是重要区域"，才能判断"当前的信号值不值得关注"。

---

### 第三步：识别 K 线形态（微观信号）

现在，把视野收回到最近 3–10 根 K 线：

```candle-demo:pattern-at-level
```

**问自己：**
- 最近是否出现了可识别的反转或延续形态？
- 这个形态的出现位置，是否恰好在关键价位附近？
- 形态出现的位置与第一步的趋势方向是否一致？

**筛选标准：**

| 信号类型 | 在趋势中的含义 |
|---|---|
| 看涨形态 + 上升趋势回调 | 顺势做多，信号可信度高 |
| 看涨形态 + 下降趋势反弹 | 逆势，需更多共振条件才考虑 |
| 看跌形态 + 下降趋势反弹 | 顺势做空/减仓，信号可信度高 |
| 看跌形态 + 上升趋势回调 | 逆势，可信度低 |

---

### 第四步：用成交量确认（力度验证）

最后，看成交量是否支持你的判断：

```candle-demo:volume-at-pattern
```

**核对清单：**
- 形态出现当天（或次日），成交量是否明显高于近期均值？
- 方向与价格变化一致吗？（上涨放量、下跌缩量 = 健康）
- 是否出现"量先于价"的现象？（成交量提前放大，预示方向）

## 完整示例演练

下面用一个实际场景走完完整的 4 步：

```candle-demo:full-analysis
```

**第一步：趋势**
→ MA20 方向向上，价格整体在 MA20 上方，**上升趋势**。

**第二步：关键价位**
→ MA20 恰好处于价格回调区域，历史上多次在此反弹，确认为**动态支撑**。

**第三步：K 线形态**
→ 回调至 MA20 附近后，出现**锤子线**——小实体在上，长下影线指向低位承接买盘。形态出现在支撑位，与上升趋势一致。✅

**第四步：成交量**
→ 锤子线当天成交量高于前三日均值，表明有资金在支撑位积极介入。✅

**综合判断**：三重共振（形态 + 位置 + 量），上升趋势回调结束可能性较高，这是一个值得关注的看涨机会。

## 常见误区与纠正

### 误区一：在震荡行情中频繁操作

**问题**：价格在 MA20 上下反复穿越，金叉死叉交替出现。

**纠正**：MA20 走平时，趋势不明，形态信号失效率高。正确做法是**等待趋势明确**后再入场。

---

### 误区二：看见形态就操作，忽略位置

**问题**：在图中间（非支撑阻力位）出现了锤子线，立刻判断底部反转。

**纠正**：形态 + 位置，缺一不可。游离在空中的形态，可信度极低。

---

### 误区三：用短周期推翻长周期判断

**问题**：日 K 线趋势明确向下，但 60 分钟线出现了金叉，据此做多。

**纠正**：应以**更长周期为主**，短周期的信号只在与长周期方向一致时才有意义。

## 分析检查清单

每次分析时，对照这份清单：

```
□ 1. 趋势
     MA20 方向是什么？（向上 / 向下 / 走平）
     价格在 MA20 上方还是下方？

□ 2. 位置
     附近是否有支撑/阻力位？
     当前价格是否处于关键区域？

□ 3. 形态
     是否出现可识别的 K 线形态？
     形态方向与趋势一致吗？

□ 4. 成交量
     形态出现时，量是否放大？
     量价关系是否健康？
```

**4 项都满足** → 可信度高，考虑操作
**3 项满足** → 中等可信度，小仓位试探
**2 项以下** → 信号不足，继续等待

---

## 小结

- **第一步**：看 MA20 方向，判断宏观趋势
- **第二步**：标注支撑/阻力关键价位
- **第三步**：在关键价位附近寻找 K 线形态信号
- **第四步**：用成交量验证信号力度
- 框架的价值在于**系统化思考**，减少冲动和遗漏
- 市场永远有不确定性，框架不能消除风险，但能帮你**在高概率区域操作**

> **最后的话**：技术分析是一门概率游戏，不是算命。每一次分析都是提高胜率，而不是寻找必胜公式。保持纪律，持续复盘，才是长期进步的关键。
