# 单根K线的四个价格

每一根K线记录了某个时间周期内的**四个关键价格**，英文缩写为 **OHLC**：

| 缩写 | 含义 | 说明 |
|---|---|---|
| **O** | Open（开盘价） | 该周期第一笔成交价 |
| **H** | High（最高价） | 该周期内价格的最高点 |
| **L** | Low（最低价） | 该周期内价格的最低点 |
| **C** | Close（收盘价） | 该周期最后一笔成交价 |

## 四价与K线结构的对应关系

```
      最高价 (High)
         │
  ┌──────┤  ← 上影线 = High - max(Open, Close)
  │      │
  │  实体 │  ← 实体 = |Close - Open|
  │      │
  └──────┤  ← 下影线 = min(Open, Close) - Low
         │
      最低价 (Low)
```

### 阳线（收盘 > 开盘）

```
       High（最高价）
        │
      ══╪══ ← Close 收盘价（实体上边）
      ║   ║
      ║   ║   绿色实体
      ║   ║
      ══╪══ ← Open  开盘价（实体下边）
        │
       Low（最低价）
```

### 阴线（收盘 < 开盘）

```
       High（最高价）
        │
      ══╪══ ← Open  开盘价（实体上边）
      ║   ║
      ║   ║   红色实体
      ║   ║
      ══╪══ ← Close 收盘价（实体下边）
        │
       Low（最低价）
```

## 影线的计算公式

- **上影线长度** = 最高价 − max(开盘价, 收盘价)
- **下影线长度** = min(开盘价, 收盘价) − 最低价
- **实体长度** = |收盘价 − 开盘价|

## 如何阅读一根K线

以某只股票某日数据为例：

```
开盘价：100.0
最高价：108.5
最低价：97.2
收盘价：106.3
```

分析：
1. 收盘价（106.3）> 开盘价（100.0）→ **阳线**（上涨 6.3%）
2. 上影线 = 108.5 − 106.3 = 2.2（相对较短，说明高点被小幅回压）
3. 下影线 = 100.0 − 97.2 = 2.8（有一定的低点支撑反弹）
4. 实体 = 106.3 − 100.0 = 6.3（实体较长，多方力量强劲）

## 成交量的配合

K线只记录价格，**成交量**是理解K线的重要辅助指标：

- **大阳线 + 放量**：突破有效，信号可靠
- **大阳线 + 缩量**：可能是虚涨，需谨慎
- **大阴线 + 放量**：抛压沉重，下跌可能持续
- **大阴线 + 缩量**：可能是洗盘，关注后续

> **记忆口诀**：开高低收四价格，阳线绿来阴线红，影线长短看多空，实体大小看力度。

## 小结

- OHLC = 开盘价、最高价、最低价、收盘价
- 上影线 = 多方上攻被压回的痕迹
- 下影线 = 空方下砸被支撑的痕迹
- 实体越长，该方向的力度越强
