# 影线的含义

影线是K线最富信息量的部分。它记录了市场在该时间周期内**曾经到达但未能守住的价格区域**，折射出多空双方博弈的过程。

## 上影线：多方攻势被压制

```candle-demo:upper-shadow
```

**上影线的含义**：

价格在周期内一度上冲至最高价，但随后遭遇**卖压**（空方入场），被压回至收盘价附近。

- 上影线**越长**，说明高位卖压越重，多方越难守住涨幅
- 上影线长 + 小实体 = **流星线**（顶部反转信号）

## 下影线：空方打压被承接

```candle-demo:lower-shadow
```

**下影线的含义**：

价格在周期内一度下探至最低价，但随后获得**买盘支撑**（多方入场），被拉回至收盘价附近。

- 下影线**越长**，说明低位买盘越积极，空方越难守住跌幅
- 下影线长 + 小实体 + 位置在低位 = **锤子线**（底部反转信号）

## 典型单根K线形态

### 锤子线（Hammer）

```candle-demo:hammer
```

- **特征**：小实体在上，长下影线，几乎无上影线
- **出现位置**：下跌趋势末端
- **含义**：空方打压至低位后，多方强力介入，价格反弹。预示底部反转
- **口诀**：锤子砸地弹，下跌末见底

### 流星线 / 射击之星（Shooting Star）

```candle-demo:shooting-star
```

- **特征**：小实体在下，长上影线，几乎无下影线
- **出现位置**：上涨趋势末端
- **含义**：多方将价格拉升至高位，但随即遭遇空方打压，价格回落。预示顶部反转
- **口诀**：流星划天弧，上涨末见顶

### 十字星（Doji）

```candle-demo:doji
```

- **特征**：开盘价与收盘价几乎相等，实体极小
- **含义**：多空双方力量相当，市场陷入犹豫。方向未定，需结合前后K线判断
- **变体**：
  - **长脚十字星**：上下影线都很长，表明激烈博弈后回到原点
  - **墓碑十字星**：只有上影线，开盘=收盘=最低价
  - **蜻蜓十字星**：只有下影线，开盘=收盘=最高价

## 多空博弈的全程视角

以一根锤子线的**形成过程**为例：

1. **开盘**：价格从某点开始
2. **盘中下跌**：空方主导，价格大幅下探（下影线形成）
3. **低位反转**：多方在低位大量买入，空方回补
4. **收盘**：价格被拉回至接近开盘位置

这个过程记录在下影线里：**每一条长下影线，都是一次多空激战的证明**。

## 影线长度的相对性

判断影线长短，需要与**实体**和**周围K线**对比：

- 影线长度 ≥ 实体长度的 2 倍：明显影线
- 影线长度 < 实体长度的 1/2：无意义的小影线
- 结合周围K线：在密集区出现的长影线，参考价值更高

> **核心记忆**：
> - 长上影线 = 高位遭打压 = 偏空信号
> - 长下影线 = 低位遭承接 = 偏多信号
> - 十字星 = 多空均衡 = 方向待定

## 小结

- 影线记录了价格曾走过但未能守住的区域
- 上影线 → 顶部压力（空方）
- 下影线 → 底部支撑（多方）
- 锤子线、流星线、十字星是最重要的单根反转信号
