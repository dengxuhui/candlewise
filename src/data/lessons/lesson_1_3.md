# 影线的语言（多空博弈）

影线是K线中信息最密集的部分。**每一条影线，都是一场多空激战的现场记录。**

---

## 上影线：空方反击，多方受阻

```candle-demo:upper-shadow
```

### 上影线的形成过程

1. 开盘后，多方推动价格上涨
2. 到达某个高位，大量卖单涌现（空方入场、获利了结）
3. 卖压压垮买盘，价格被推回，收盘远低于最高价
4. 最高价到收盘价之间的细线 = **上影线**

### 上影线越长意味着什么

- 上影线越长 → 多方上攻越强烈，但空方也反击得越猛
- 最终结果：多方没能守住高点，偏**空方压制**信号

### 典型形态：流星线（顶部）

当上影线极长、实体极小、几乎无下影线，且出现在上涨末端时，就是**流星线**（Shooting Star）——强烈的顶部警示信号。

---

## 下影线：多方接盘，空方受挫

```candle-demo:lower-shadow
```

### 下影线的形成过程

1. 开盘后（或盘中），空方推动价格下跌
2. 到达某个低位，大量买单涌现（多方抄底、止跌护盘）
3. 买盘压垮卖盘，价格被拉回，收盘远高于最低价
4. 最低价到开盘/收盘价之间的细线 = **下影线**

### 下影线越长意味着什么

- 下影线越长 → 空方打压越深，但多方也接盘越积极
- 最终结果：空方没能守住低点，偏**多方支撑**信号

### 典型形态：锤子线（底部）

当下影线极长（通常为实体的 2 倍以上）、实体极小、几乎无上影线，且出现在下跌末端时，就是**锤子线**（Hammer）——经典的底部反转信号。

```candle-demo:hammer
```

---

## 十字星：多空均衡，变盘前夕

```candle-demo:doji
```

### 十字星的形成

当收盘价与开盘价几乎相等时，实体趋近于零，形成**十字星**（Doji）。

这意味着：**多空双方势均力敌，在这个时间周期内谁也没赢**。

### 十字星的三种变体

| 变体 | 外形特征 | 多空含义 |
|---|---|---|
| **标准十字星** | 上下影线接近等长 | 多空平衡，方向未定 |
| **墓碑十字星** | 只有长上影线，无下影线 | 上冲失败，偏看跌 |
| **蜻蜓十字星** | 只有长下影线，无上影线 | 下探被接，偏看涨 |

> 十字星本身只是"信号"，不是"结论"——需要结合**出现位置**和**后续K线**确认方向。

---

## 影线判读的相对性原则

影线的意义需要与**周围K线**对比，不能孤立判断：

- 单根长下影线在连续暴跌后 → 底部反转意义强
- 同样的长下影线在上升途中随机出现 → 意义弱，可能只是正常波动
- 影线需与同期其他K线的**平均振幅**对比才有参考价值

---

## 综合对比速查表

| 影线类型 | 信号偏向 | 对应形态 |
|---|---|---|
| 长上影线 + 小实体（上涨末端） | 顶部看跌 | 流星线 |
| 长下影线 + 小实体（下跌末端） | 底部看涨 | 锤子线 |
| 上下影线均长 + 小实体 | 多空均衡，变盘待确认 | 十字星 |
| 几乎无影线 + 长实体 | 强方向延续 | 大阳线 / 大阴线 |

---

## 小结

- **上影线** = 高位遭空方打压，多方失守 → 偏空信号
- **下影线** = 低位被多方接盘，空方失守 → 偏多信号
- **十字星** = 多空势均力敌，变盘前兆，需后续确认
- 影线的意义来自**对比**：长短是相对概念，位置才是关键
