# 读懂一根K线（实体与影线）

上一节学了K线的结构组成，这节课我们深入拆解：**如何从一根K线读出有用的信息？**

---

## 实体：多空博弈的净结果

实体的**长度**和**颜色**是K线最直观的信息。

### 大阳线 —— 多方强势主导

```candle-demo:ohlc-bullish
```

- 实体长、涨色（收盘远高于开盘）
- 说明：买盘持续涌入，全天基本没有回头，空方无力抵抗
- **含义**：多方强势，短期看涨偏强

### 大阴线 —— 空方强势主导

```candle-demo:ohlc-bearish
```

- 实体长、跌色（收盘远低于开盘）
- 说明：卖盘持续施压，全天基本没有反弹，多方无力抵抗
- **含义**：空方强势，短期看跌偏强

### 实体越长，方向越确定

| 实体长度 | 信号强度 |
|---|---|
| 实体 > 当日振幅的 60% | 强方向信号（大阳线或大阴线） |
| 实体占振幅的 30%~60% | 中等强度 |
| 实体 < 振幅的 30% | 方向不明，需看影线 |

> **振幅** = 最高价 − 最低价

---

## 影线：被压制的极端价格

影线记录的是价格**曾经到达但没能守住**的区域，是多空双方激战的"战场痕迹"。

### 上影线计算

```
上影线长度 = 最高价 − max(开盘价, 收盘价)
```

上影线越长，代表高位曾有大量卖盘压制，多方上攻未果。

### 下影线计算

```
下影线长度 = min(开盘价, 收盘价) − 最低价
```

下影线越长，代表低位曾有大量买盘托底，空方打压未能守住。

---

## 读图练习：拆解一根真实K线

假设某日数据如下：

```
开盘价：100.0
最高价：112.0
最低价：94.0
收盘价：108.5
```

逐步分析：

1. 收盘（108.5）> 开盘（100.0）→ **阳线**，多方胜
2. 实体 = 108.5 − 100.0 = **8.5**
3. 振幅 = 112.0 − 94.0 = **18.0**
4. 实体占振幅 = 8.5 / 18.0 ≈ 47% → **中等强度**
5. 上影线 = 112.0 − 108.5 = **3.5**（较短，顶部压力不强）
6. 下影线 = 100.0 − 94.0 = **6.0**（相对较长，低位有买盘承接）

**综合解读**：这是一根带有较长下影线的阳线，低位承接力度不错，但顶部有小幅卖压，多方占优但尚未完全主导。

## 成交量：K线的"置信度"

K线只记录价格，**成交量**补充了"有多少人参与了这场博弈"的信息：

| 组合 | 解读 |
|---|---|
| 大阳线 + 放量 | 突破或趋势加速，信号可信度高 |
| 大阳线 + 缩量 | 可能是虚涨，买盘不厚实 |
| 大阴线 + 放量 | 抛压沉重，下跌有资金推动 |
| 大阴线 + 缩量 | 可能是洗盘，卖盘不充裕 |

> 本平台的K线图暂时不显示成交量柱，但在实盘中请养成**同时看量**的习惯。

---

## 小结

- 实体 = 开盘价与收盘价之差，代表多空净结果
- 实体越长 → 方向越明确；实体越短 → 多空越拉锯
- 上影线越长 → 顶部卖压越重；下影线越长 → 底部买盘越强
- 成交量是K线信号的"置信度放大镜"

> **记忆口诀**：实体看方向，影线看力量，量能做验证。
