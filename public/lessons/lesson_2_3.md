# 十字星家族

**十字星**（Doji）是一类特殊的 K 线：开盘价与收盘价几乎相等，实体极小或为零。它代表市场中**多空力量的极度均衡与迷茫**，通常出现在趋势转折点附近，是重要的不确定性信号。

---

## 标准十字星（Doji）

### 形态结构

```candle-demo:doji
```

### 形态特征

| 要素 | 标准 |
|---|---|
| 实体大小 | 极小（开盘价 ≈ 收盘价） |
| 上影线 | 存在 |
| 下影线 | 存在 |
| 含义 | 多空势均力敌，方向不明 |

### 信号含义

十字星本身是**中性信号**，单独出现意义有限。关键在于它出现的位置：

- **出现在下跌趋势末端** → 潜在底部反转信号（看涨）
- **出现在上涨趋势末端** → 潜在顶部反转信号（看跌）
- **出现在横盘中** → 意义不大，继续观望

---

## 十字星的变体

十字星家族根据上下影线的相对长度，分为多种变体，各有不同的含义：

### 墓碑十字星（Gravestone Doji）

| 特征 | 说明 |
|---|---|
| 上影线 | 很长 |
| 下影线 | 极短或无 |
| 实体 | 位于 K 线最底部 |
| 信号 | **看跌**，形似流星线，多方拉升失败 |

出现在上涨末端时，是较强的**顶部反转**信号。

### 蜻蜓十字星（Dragonfly Doji）

| 特征 | 说明 |
|---|---|
| 下影线 | 很长 |
| 上影线 | 极短或无 |
| 实体 | 位于 K 线最顶部 |
| 信号 | **看涨**，形似锤子线，下方买盘强劲 |

出现在下跌末端时，是较强的**底部反转**信号。

### 长腿十字星（Long-legged Doji）

| 特征 | 说明 |
|---|---|
| 上下影线 | 均很长 |
| 实体 | 居中，极小 |
| 信号 | **高度不确定性**，市场剧烈波动后回归原点 |

---

## 十字星家族总览

| 类型 | 形态 | 信号 | 可靠性 |
|---|---|---|---|
| 标准十字星 | 上下影线均有，实体极小 | 中性，位置决定方向 | 需确认 |
| 墓碑十字星 | 长上影，无下影 | 看跌（顶部） | 中等 |
| 蜻蜓十字星 | 长下影，无上影 | 看涨（底部） | 中等 |
| 长腿十字星 | 上下影均长 | 高度不确定 | 低，需观望 |

---

## 关键原则

### 1. 位置第一

十字星的信号方向**完全由出现位置决定**，孤立的十字星几乎没有交易意义。

### 2. 确认优先

十字星是"犹豫信号"，不是"确认信号"。必须等待**次日 K 线的方向确认**：

- 次日收阳线 → 确认看涨反转
- 次日收阴线 → 确认看跌反转

### 3. 组合更可靠

十字星与其他信号组合时可靠性显著提升，例如：
- 启明星中的"星"（第2根）就常常是十字星
- 十字孕线（Harami Cross）将在双根形态中专门讲解

---

## 小结

- **十字星** = 开盘 ≈ 收盘，多空均衡，方向未定
- 四种变体：标准、墓碑（看跌）、蜻蜓（看涨）、长腿（不确定）
- 信号方向由**出现位置**决定，需要**次日确认**
- 十字星家族是市场"转折预兆"，而非直接的买卖信号
