# 角色转换与成交量确认

上一课我们学习了支撑与阻力。这节课进一步讲解两个关键概念：**角色转换**（Role Reversal）——支撑与阻力如何相互转化，以及**成交量**如何用来验证价格突破的真实性。

---

## 角色转换：支撑变阻力

当价格**有效跌破**支撑位后，原来的支撑位往往**转变为阻力位**。

```candle-demo:support-to-resistance
```

### 为什么会发生角色转换？

跌破支撑意味着在该价位**买入的人开始亏损**。当价格反弹回到该价位时，这批被套的买家倾向于**止损出局**——他们的卖出行为在原支撑位形成了新的卖压，也就是阻力。

> **套牢盘心理**：在 100 元买入、被跌至 90 元的投资者，当价格反弹回 100 元时，往往选择"解套离场"而非继续持有。

---

## 角色转换：阻力变支撑

当价格**有效突破**阻力位后，原来的阻力位往往**转变为支撑位**。

```candle-demo:resistance-to-support
```

### 为什么会发生角色转换？

突破阻力意味着在该价位**看空的人开始亏损**。当价格回踩到该位置时，此前持有的多方会**加仓保护**，形成新的买盘支撑。

| 情境 | 转变逻辑 |
|---|---|
| 支撑被跌破 → 变阻力 | 被套多方在原位减仓，形成卖压 |
| 阻力被突破 → 变支撑 | 持仓多方在原位加仓，形成买盘 |

---

## 成交量：价格的验证器

价格本身只能告诉你**方向**，成交量能告诉你这个方向有没有**真实的资金支持**。

### 放量突破——可信度高

```candle-demo:volume-breakout
```

价格在整理后**放量突破**阻力位，意味着大量资金参与推动，突破具有实质意义。

### 缩量假突破——警惕

```candle-demo:volume-fake-breakout
```

若突破时成交量极小，说明参与者寥寥，多为**试探性行为**。这种突破往往很快回落，被称为"假突破"（False Breakout）。

---

## 成交量与 K 线形态的配合

| 场景 | 量价关系 | 信号解读 |
|---|---|---|
| 锤子线 + 放量 | 量价配合 | 底部反转可信度高 |
| 锤子线 + 缩量 | 量价背离 | 反转信号弱，需等待确认 |
| 阳线突破 + 放量 | 量价配合 | 突破有效，趋势延续 |
| 阳线突破 + 缩量 | 量价背离 | 假突破风险高 |

```candle-demo:volume-confirm
```

锤子线出现后，次日放量大阳线确认，反转信号大幅增强。

---

## 角色转换 + 量能 = 完整判读框架

实战中最可靠的信号往往是：
1. 价格**放量突破**阻力位（或放量跌破支撑位）
2. 随后**回踩**该价位时，量能萎缩（说明无大量抛盘）
3. 在回踩位置出现**反转 K 线形态**（如锤子线、吞没）

这三步配合，就是"角色转换 + 量能确认 + 形态信号"的完整闭环。

---

## 小结

- **支撑变阻力**：跌破支撑后，被套多方在原位减仓，形成卖压
- **阻力变支撑**：突破阻力后，持仓多方在原位加仓，形成买盘
- **放量突破** = 真实有效；**缩量突破** = 假突破风险高
- 成交量是 K 线形态信号的重要验证维度，不可忽视
